# Semana 1 – Requerimientos de interfaz y flujos de usuario

| Código | Requerimiento | Semana |
|---|---|---|
| RI-01 | Aplicación web de una sola página (SPA) con React y enrutamiento. | 2 |
| RI-02 | Sistema de diseño con colores, tipografía y componentes reutilizables. | 2 |
| RI-03 | Layout con menú, encabezado, pantalla de carga y pantalla de error. | 3 |
| RI-04 | Catálogo de instrumentos con filtros (texto, categoría, tipo, ciudad). | 3–4 |
| RI-05 | Detalle de instrumento con comparación de precios entre tiendas. | 4 |
| RI-06 | Mapa interactivo de tiendas cercanas con Geolocation API. | 4 |
| RI-07 | Login por rol y paneles de Encargado y Administrador. | 5+ |
| RI-08 | Consentimiento, prueba de vida y autocompletado del carnet. | 7–8 |
| RI-09 | Diseño responsivo (móvil y escritorio) y manual de usuario. | 9, 12 |

## No funcionales
* Accesible: etiquetas en formularios, roles ARIA en estados de carga y error.
* Resiliente: si el backend no responde, muestra datos de prueba y lo avisa.
* Responsivo desde el inicio (cuadrícula adaptable).
